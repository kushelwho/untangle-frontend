# 💸 Untangle Frontend — Web Application & SPA

<p align="center">
  <strong>A modern, responsive React 19 + Vite single-page application (SPA) for the Untangle expense-sharing and debt-simplification platform.</strong>
</p>

---

## 🌟 Highlights & Features

- **React 19 + Vite 8**: Blazing-fast development server with Hot Module Replacement (HMR) and optimized production static bundles.
- **Multi-Strategy Expense Split UI**: Interactive forms supporting **Equal**, **Percentage**, and **Exact Amount** split modes with instant client-side validation.
- **Real-Time Debt Simplification**: Visualizes multi-party cyclic debts and presents the minimal settlement transaction plan generated by the backend.
- **Email & UUID Group Membership**: Add members effortlessly by their email address or unique ID.
- **Responsive Modern UI**: Rich aesthetics with clean layout, modal dialogs, and instant visual feedback.

## 🚀 Quick Start (Local Development)

### 1. Prerequisites
- **Node.js 20+** (LTS recommended)
- **npm 10+**
- **Untangle Backend API** running locally on `http://localhost:8080`

### 2. Install Dependencies & Run Dev Server
```bash
# Install packages
npm install

# Start local Vite development server
npm run dev
```

By default, the Vite dev server runs at **`http://localhost:5173`** and automatically proxies all `/api` requests to `http://localhost:8080` (see `vite.config.js`).

## 🐳 Production Docker Deployment

The repository includes a multi-stage **Dockerfile** that compiles the React app and serves it using a lightweight **Nginx Alpine** container:

```bash
# 1. Build the Docker image
docker build -t untangle-frontend .

# 2. Run the container on port 80
docker run -d -p 80:80 --name untangle-web untangle-frontend
```

### Nginx Features (`nginx.conf`):
- **SPA Client-Side Routing Fallback**: Automatically redirects unknown paths to `/index.html` so React Router works on direct page reloads.
- **Built-in `/api` Reverse Proxy**: Routes requests to `http://api:8080/api/` when deployed alongside the backend in a Docker network or Docker Compose stack.
- **Gzip Compression**: Compresses HTML, CSS, JS, and JSON payloads for fast page loads.

## ⚙️ Environment Configuration

Copy `.env.example` to `.env` if you need to override the backend API URL:

```bash
cp .env.example .env
```

| Variable | Default Value | Description |
| :--- | :--- | :--- |
| `VITE_API_BASE_URL` | `/api` | Base API endpoint for backend calls. When set to `/api`, Vite dev proxy or Nginx production proxy handles routing automatically. |
